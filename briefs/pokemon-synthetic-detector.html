Pokémon synthetic-data detector

Overview

I built a computer vision experiment to explore how training on generated images can support object detection. The project connects a Unity data generator, a Python detector, and an iPhone app.

My contribution

I built a generator that varies scenes and produces labeled images, then developed workflows to validate data and train and evaluate a YOLO detector. I also built live webcam detection and an iPhone app with on-device inference and detection overlays. The documented model evaluation uses synthetic test images.

Technologies used

  • Unity
  • Python
  • YOYOLO
  • OPOpenCV
  • SWSwift
  • COCore ML
